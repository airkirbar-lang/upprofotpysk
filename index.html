Параметры Firebase-проекта
Создайте проект на console.firebase.google.com → Realtime Database → «Создать базу». Скопируйте сюда:
Для теста установите в правилах БД:
{ "rules": { ".read": true, ".write": true } }
Для продакшена ограничьте доступ по домену/токену.
